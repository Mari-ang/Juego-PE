## 📋 Especificaciones del Proyecto

- **Motor de juego**: Godot
- **Lenguaje**: GDScript
- **Plataforma(s)**: PC
- **Modo de juego**: Un jugador

### 🎮 Características principales:

- Se puede mover en 3 diferentes direcciones y puedes caer gracias a l GRAVEDAD.
- Puedes tomar monedas los cuales haran que tu salto aumente.
- Tiene plataformas en movimiento.
- Tiene un generador de balas.
- Tiene una platadforma en la que no puedes sufir daño.
